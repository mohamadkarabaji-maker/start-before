# START BEFORE — نسخة أولية متصلة بالذكاء الاصطناعي

## ما الذي أصبح يعمل؟
- نموذج إدخال المشروع بثلاث لغات: العربية والفرنسية والإنجليزية.
- إرسال بيانات المشروع إلى خادم خلفي بدلاً من وضع مفتاح API في المتصفح.
- إنشاء تقرير مخصص عبر OpenAI Responses API باللغة المختارة.
- معالجة أخطاء الاتصال ومفتاح API.

## المتطلبات
- Node.js 20 أو أحدث.
- مفتاح OpenAI API صالح مع تفعيل الفوترة/الرصيد المناسب في حساب API. اشتراك ChatGPT لا يتضمن تلقائياً رصيد API.

## التشغيل على جهازك
1. فك ضغط الملف.
2. انسخ `.env.example` إلى ملف اسمه `.env`.
3. افتح `.env` وضع مفتاحك مكان `your_api_key_here`.
4. ثبّت الاعتماديات: `npm install`.
5. شغّل: `npm start`.
6. افتح `http://localhost:3000` في المتصفح.

## حماية المفتاح
- لا تضع مفتاح API داخل `index.html` أو أي كود يعمل في المتصفح.
- لا ترفع ملف `.env` إلى GitHub ولا ترسله في المحادثات.
- ضع حدود استخدام ومصادقة ومراقبة للتكلفة قبل نشر الموقع للعامة؛ هذه النسخة نموذج أولي وليست جاهزة للإطلاق التجاري المفتوح.

## ملاحظات مهمة
- الذكاء الاصطناعي قد يخطئ. لا تعتمد على التقرير وحده لاتخاذ قرار مالي أو قانوني.
- لا توجد حالياً حسابات مستخدمين أو دفع أو حفظ تقارير في قاعدة بيانات.
- لا توجد دراسة سوق مباشرة أو بيانات منافسين حية؛ سيقترح النظام طرق تحقق بدلاً من اختلاق بيانات.
